# Store SSH endpoint settings in Tunnel Profiles

Tunnel Profiles store their SSH hostname, port, optional username, and authentication method instead of requiring a `Host` alias from `~/.ssh/config`. This makes EZ Tunnel self-contained and lets users configure a tunnel without editing another file. SSH Agent/System Default remains the preferred authentication method; a selected private-key path may be stored in profile JSON, while password and key passphrase values must be stored only in macOS Keychain and never in profile JSON or process arguments. Password authentication is interactive/manual-only; unattended start and reconnect require an agent or non-interactive private key. EZ Tunnel continues to execute `/usr/bin/ssh` and must pass explicit endpoint options so unrelated OpenSSH configuration cannot silently replace profile values. This supersedes ADR 0003 and ADR 0004.
